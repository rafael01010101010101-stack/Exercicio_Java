# Exercícios de Java

Este repositório contém uma coleção de exercícios desenvolvidos em **Java**, com o objetivo de praticar e aprimorar os conhecimentos em lógica de programação e nos fundamentos da linguagem.

## Funcionalidades

O programa possui um menu interativo com 22 exercícios, abordando:

- **Entrada e saída de dados:** leitura e exibição de informações utilizando `Scanner`.
- **Condicionais:** utilização de `if`, `else` e validações.
- **Operações matemáticas:** soma, subtração, multiplicação, divisão e média.
- **Estruturas de repetição:** utilização de `for` e `while`.
- **Vetores:** declaração, preenchimento, leitura e manipulação de valores.
- **Matrizes:** criação, preenchimento, exibição, pesquisa de valores e manipulação de linhas e colunas.

## Tecnologias utilizadas

- Java
- Visual Studio Code
- Git e GitHub

## Objetivo

Praticar os principais fundamentos da programação em Java, desenvolvendo o raciocínio lógico e adquirindo experiência na resolução de problemas por meio de exercícios práticos.
